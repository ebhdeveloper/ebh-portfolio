# رزومه را چطور به‌روز کنم؟

سه فایل رزومه همان منبع اصلی پروژه‌اند. متن انگلیسی را در فیلد اصلی می‌نویسم و فارسی را کنار همان متن، داخل بخش ترجمه می‌گذارم. این‌طوری تاریخ، لینک و شناسه را فقط یک بار عوض می‌کنم.

برای نمونه، یک پروژه این شکلی می‌شود:

<div dir="ltr" align="left">

```json
{
  "id": "new-project",
  "title": "New Project",
  "description": "A mobile application for managing daily tasks.",
  "type": "mobile",
  "technologies": ["React Native", "TypeScript"],
  "translations": {
    "fa": {
      "title": "پروژهٔ جدید",
      "description": "اپلیکیشن موبایل برای مدیریت کارهای روزانه."
    }
  }
}
```

</div>

این فقط نمونهٔ ساختار است؛ اطلاعات واقعی پروژه را خودم وارد می‌کنم. با اضافه شدن همین رکورد به فایل رزومه، پروژه در پورتفولیو، پیش‌نمایش رزومه و PDF دیده می‌شود. در نسخهٔ آنلاین، تغییر بعد از بیلد و دیپلوی منتشر می‌شود.

در هر تجربه، نام شرکت، عنوان شغلی، محل همکاری و همهٔ دستاوردها ترجمه می‌شوند. تعداد دستاوردهای فارسی و انگلیسی باید برابر باشد؛ اگر یک دستاورد جدید اضافه کنم، ترجمه‌اش را هم اضافه می‌کنم. شناسه، تاریخ شروع و پایان و لینک‌ها داخل ترجمه نمی‌آیند. نام فناوری‌هایی مثل React و TypeScript مشترک است.

اگر یک رکورد تازه هنوز ترجمه نشده باشد، متن انگلیسی خودش با جهت درست نشان داده می‌شود. اطلاعات پایه هم همین ساختار ترجمه را دارد: نام، عنوان، معرفی و شهر. گروه مهارت فقط نام گروه را ترجمه می‌کند؛ کلیدواژه‌های فنی مشترک‌اند. برای تحصیلات، نام دانشگاه، رشته و مقطع ترجمه می‌شوند.

در صفحهٔ فارسی، رزومه و PDF فارسی‌اند؛ در صفحهٔ انگلیسی، انگلیسی. دکمهٔ زبان بالای رزومه همان نسخه را به زبان دیگر باز می‌کند. تاریخ‌ها میلادی می‌مانند؛ فقط ارقام و نام ماه در نسخهٔ فارسی فارسی می‌شوند.

قبل از پوش، تست، بررسی تایپ و بیلد را اجرا می‌کنم:

<div dir="ltr" align="left">

```bash
npm test
npm run typecheck
npm run build
```

</div>

فول‌استک فعلاً اطلاعات تماس دارد. ساختار دو‌زبانه برایش آماده است؛ سابقه و مهارت‌های واقعی را بعداً به همان فایل اضافه می‌کنم.
